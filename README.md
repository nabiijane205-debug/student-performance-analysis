# Student Performance Analysis

## Project Overview

This project analyses student academic performance using the UCI Student Performance dataset. The aim is to investigate how study habits, previous academic failures and school attendance relate to students' final mathematics grades.

The analysis was conducted using Microsoft Excel, with the goal of identifying patterns and presenting meaningful insights through a dashboard.

## Objectives

- Analyse the distribution of students across different performance levels.
- Investigate the relationship between study time and final grades.
- Examine how previous academic failures relate to student performance.
- Explore the relationship between school absences and final grades.
- Present key findings through a visual dashboard.

## Dataset

The project uses the Student Performance dataset from the UCI Machine Learning Repository.

- Students analysed: 395
- Original variables: 33
- Subject analysed: Mathematics
- Target variable: `G3` (final grade, out of 20)

Dataset source: https://archive.ics.uci.edu/dataset/320/student+performance

## Tools Used

- Microsoft Excel
- Excel Tables
- Excel formulas and functions
- PivotTables
- Charts and data visualisation

## Analysis Performed

### 1. Student Performance Distribution
Students were grouped into four performance categories:

- Very Low: 0–5
- Low: 6–10
- Moderate: 11–15
- High: 16–20

### 2. Study Time vs Academic Performance

Examined the average final grade across different weekly study-time groups.

### 3. Previous Failures vs Academic Performance

Investigated how the number of previous class failures relates to final mathematics grades.

### 4. School Absences vs Academic Performance

Compared average final grades across different absence ranges.

### 5. Combined Analysis

Used a PivotTable to examine the relationship between study time, previous failures and final grades.
